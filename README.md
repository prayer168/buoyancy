# 浮力探險所

適合國小高年級的七頁籤互動數位教材。學生透過壓力與受力示意、沉浮變因實驗、分段動畫、八個生活應用與十題闖關，理解浮力、排開流體、平均密度及沉浮判斷。

## 學習契約

- 年級：國小五至六年級
- 先備知識：質量、體積、力的方向、簡單小數比較
- 使用情境：一節課教師引導，或學生兩節課自主探究
- 核心迷思：重物一定沉；下沉物體沒有浮力；物體越深浮力一定越大

| 學習目標 | 畫面／互動 | 學生行動 | 成功證據 |
|---|---|---|---|
| 辨認浮力與重量 | 探索頁受力示意 | 比較箭頭方向與大小 | 說出浮力向上、重量向下 |
| 解釋浮力來源 | 四階段動畫 | 逐步觀察壓力箭頭 | 以深度造成的壓力差解釋淨向上力 |
| 判斷沉浮 | 沉浮實驗室 | 控制質量、體積、液體密度 | 能先預測並用平均密度、受力數值修正 |
| 遷移至生活 | 八張翻牌卡與闖關 | 比較、解釋、作答 | 能用排水體積或平均密度解釋新場景 |
